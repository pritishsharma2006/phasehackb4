# Usage Instructions

## Starting the Frontend
To start the frontend, use the following command:
```bash
npm run dev
```
The frontend will be served at [localhost:5173](http://localhost:5173) using Vite v5.4.21.

## Starting the Backend
To start the backend, use:
```bash
uvicorn main:app --reload
```
This will run the backend server and automatically reload any changes you make to the code.
